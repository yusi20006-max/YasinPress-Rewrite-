# Repository Certification

**Status: GREEN**

The repository-side certification gate is complete on `main`.

This certification covers source, tests, packaging, CLI startup, CI command parity, runtime/queue separation, persistence/idempotency, freshness/rate limits, and credential-free publication contracts.

## Explicitly excluded

This document does not certify Termux execution, live Eitaa delivery, production AI credentials, or public PWA/RSS hosting.

Those are operational release gates and must be verified separately before calling the release production-certified.
